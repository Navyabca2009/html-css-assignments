Assignment 1 – What happens between typing a URL and seeing the page?
first , we write an URL on the browser's search bar and then press enter. then browser check its cheche and find its IP address and if its not found then browser ask to DNS resolver to find IP address from the domain name. Nom, browser connects with web sever through that IP address then the browser sends a request to the web server in http/https. Now, web server receives the request and process it and sends the response to the browser in the required file such as ( HTML , CSS, IMAGE, JAVASCRIPT ).NOW ,browser receives the response and execute it in the form of web page .
